# Дисклеймер

Проект создан в учебных целях и для личного использования.

- Скрипт скачивает только серии, которые API Koroche помечает как бесплатные
  (`paid_access.type == "free"`). Платные (`locked`) серии не трогает.
- Массовое скачивание может нарушать Условия использования сервиса Koroche и
  привести к блокировке устройства или IP.
- Скачанные файлы — только для личного просмотра. Распространение может нарушать
  авторские права правообладателей.
- Автор и контрибьюторы не несут ответственности за использование инструмента.

Используя этот код, вы берёте ответственность на себя.
